# SpiritualPetal Static Website

This is a plain HTML/CSS website designed for GitHub Pages.

## Files

- `index.html` — homepage
- `copper-bottle.html` — dedicated hammered copper water bottle page
- `incense-burner.html` — dedicated incense burner page
- `styles.css` — shared responsive styling
- `assets/` — product photographs and the supplied SpiritualPetal logo

## GitHub Pages

1. Create a GitHub repository, for example `spiritualpetal-website`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save. GitHub will provide your Pages URL.

## Important

The eBay buttons currently use eBay search URLs so the site works immediately. Replace those URLs with your actual eBay listing URLs when your listings are ready.

The wellness language intentionally describes traditional Indian/Ayurvedic context rather than making medical treatment claims.
